
# 🎮 Tic Tac Toe

A modern, interactive Tic Tac Toe game built using **Python, Flask, HTML, CSS, and JavaScript**.

## ✨ Features

- Modern and responsive user interface
- Two-player mode (Player vs Player)
- Play against the computer
- Easy and Hard difficulty levels
- Hard mode uses the Minimax algorithm
- Live scoreboard for wins and draws
- Winning combination highlighting
- Restart game and reset scoreboard options
- Dark and light themes
- Simple sound effects

## 🛠️ Technologies Used

- **Python** – Backend
- **Flask** – Web framework
- **HTML** – Structure
- **CSS** – Styling and animations
- **JavaScript** – Game logic and interactions

## 🚀 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Divyanshu659-cyber/tic-tac-toe.git
```

### 2. Open the project folder

```bash
cd tic-tac-toe
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in your browser

Visit:

```text
http://127.0.0.1:5000
```

## 🎯 How to Play

1. Select your preferred game mode.
2. Choose whether to play against another player or the computer.
3. Take turns selecting empty cells.
4. Get three matching symbols in a row, column, or diagonal to win.
5. Use the restart button to play again.

## 🧠 AI Difficulty

- **Easy:** The computer makes random moves.
- **Hard:** The computer uses the Minimax algorithm to make optimal moves.
